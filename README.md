#  BlueKart Admin Dashboard

**BlueKart Admin Dashboard** is a frontend-only e-commerce admin panel built using **HTML, CSS, and Vanilla JavaScript**. It allows admins to manage products, orders, customers, and view sales analytics through interactive charts.

---

##  Features
- Overview dashboard with key metrics
- Product management (Add / Edit / Delete)
- Order management with status tracking
- Customer management
- Monthly sales & weekly orders charts (Chart.js)
- Search products by name or ID
- Data persistence using `localStorage`
- Responsive UI

---

##  Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- Browser `localStorage`

---

##  How to Run
1. Download the project files
2. Open `index.html` in a modern browser
3. Dashboard loads with mock data automatically

_No backend or server required._
